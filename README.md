# PicGrid — Discover High-Res Visuals

PicGrid is an image-search web application built using HTML, CSS, and JavaScript. Users can search for topics or explore curated categories to fetch image galleries.

## Part 1 Design Decisions

1. **Category Quick-Pick Chips:** Added interactive category tags below the search bar so users can quickly explore common topics with a single click without needing to type.
2. **Empty-State Guidance:** Placed a placeholder state message below the search bar to guide first-time visitors on what action to take before any search query is submitted.
3. **Dark Modern Theme:** Chose a deep navy slate (`#0f172a`) and cyan (`#06b6d4`) palette to offer a modern dark-mode feel distinct from standard layouts.
